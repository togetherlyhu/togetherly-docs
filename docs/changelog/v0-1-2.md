# 🧹 v0.1.2

**Kiadás dátuma:** 2026. július

## ⚙️ Technikai változások

### 🧹 ESLint hibák javítása

- Eltávolítottuk a nem használt importokat, köztük a `redirect`, `fail`, és lucide ikon importokat, több mint 20 fájlból.
- A komponensekből töröltük a nem használt változókat és propokat.
- Az `{#each}` blokkok egyedi kulcsokat kaptak a Svelte 5 követelményeinek megfelelően.
- Az üres `catch` blokkok `// Ignore` megjegyzést kaptak a `no-empty` szabály teljesítéséhez.
- Az admin service `no-explicit-any` problémái típusos `Record<string, unknown>` használatára váltottak.
- Javítottuk a `prefer-const` problémákat a dispatcherben.
- A reaktivitás biztosítására natív `Set` helyett `SvelteSet` használatos.
- Helyreállt a `$state()` és `$derived()` helyes használata a Svelte 5 runes szabályai szerint.
- Javítottuk az admin layout `@typescript-eslint/no-unused-expressions` jelzését.
- A MarkdownRendererben megjegyzéssel dokumentáltuk a `svelte/no-at-html-tags` kivételt.

### 🧪 svelte-check figyelmeztetések javítása

- A form state változóknál a `state_referenced_locally` figyelmeztetések megszűntek.
- Az auth verify oldalon `$state()` használatával javult a `non_reactive_update` hiba.
- A `line-clamp` standard CSS tulajdonság a vendor prefix mellé került.
- A vezérlők és címkéik `for` attribútummal kapcsolódnak.
- Hét fájlban javult a `Property 'form' does not exist` típushiba.
- Az auth verify oldal `inputEl` lehetséges undefined állapota kezelve van.

### 🎨 Prettier formázás

- A teljes kódbázis egységes Prettier formázást kapott.
- 63 fájl formázása történt meg, többek között Svelte komponensekben, TypeScript service-ekben és API route-okban.
