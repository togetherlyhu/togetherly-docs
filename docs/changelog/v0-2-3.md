# ✨ v0.2.3

**Kiadás dátuma:** 2026. november 17.

Ez a kiadás egy új admin kapcsolót hoz a regisztrációk szüneteltetéséhez, valamint verzióinformációt és frissítésjelzést a láblécben. Emellett számos felületi és megbízhatósági fejlesztés is érkezett.

## 🔒 Regisztrációk kezelése

- Új admin kapcsoló a regisztrációk szüneteltetéséhez.
- Szüneteltetés esetén csak a meglévő felhasználók tudnak bejelentkezni.
- A karbantartási móddal összhangban az admin e-mailek továbbra is regisztrálhatnak.

## 🏷️ Lábléc és verzióinformáció

- Kompakt verzióinformáció és szerzői jogi sor a kezelőpulton.
- A verziószámra kattintva új lapon megnyílik az adott kiadás changelogja.
- Frissítésjelzés, ha újabb verzió érhető el a hivatalos API-n.
- A fő láblécben is megjelenik a verzióinformáció és a frissítésjelzés.

## ✨ Felhasználói élmény

- Vissza gomb a randi részletek oldal tetején.
- Jogi linkek (felhasználási feltételek, adatvédelem) ikonokkal a mobil "Továbbiak" menüben.
- Megbízhatóbb toast-üzenetek bejelentkezéskor (elavult értesítések megszüntetése).

## ⚙️ Technikai változások

- Új app beállítás: `registrationPaused`.
- Verzió-összehasonlítás és hivatalos API ellenőrzés a frissítésjelzéshez.
- Kisebb felületi és megbízhatósági fejlesztések.
